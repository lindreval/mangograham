================================================================================
                        AUTHENTICATION FLOW
================================================================================

Login:
  1. User clicks "Sign in with Google"
  2. Redirected to Google OAuth consent
  3. Google returns credentials
  4. User created in DB with auto-generated username
  5. Database session created
  6. Cookies set with session token

Session Structure:
  {
    user: {
      id: string (CUID)
      role: "user" | "admin"
      name?: string
      email?: string
      image?: string
    }
  }

Logout:
  - Session deleted from database
  - Cookies cleared

Protected Endpoint Pattern:
  const session = await getServerSession(authConfig)
  if (!session?.user?.id) {
    return NextResponse.json({ error: "Unauthorized" }, { status: 401 })
  }

Admin Check Pattern:
  if (session.user?.role !== "admin") {
    return NextResponse.json({ error: "Unauthorized" }, { status: 403 })
  }

================================================================================
                        CONTENT STATUS FLOW
================================================================================

Submission Status Flow:

  User Submits
      ↓
  "pending" status
      ↓
  ┌─────────────────────────────────────┐
  │  Admin Reviews on Moderation Panel   │
  └─────────────────────────────────────┘
      ↓
      ├→ APPROVED → "approved" → Visible to public
      │
      ├→ REJECTED → "rejected" → Not visible
      │
      └→ [Stays pending if not acted upon]

User Flagging:
  Approved content → POST /api/flag-definition → Status becomes "needs review"
  Admin can then approve/reject

                        COMMON PATTERNS
================================================================================

Error Handling:
  try {
    // endpoint logic
    return NextResponse.json(successData)
  } catch (error) {
    console.error("Error:", error)
    return NextResponse.json(
      { error: "Human-readable message" },
      { status: 500 }
    )
  }

Pagination:
  const page = parseInt(searchParams.get("page") || "1")
  const limit = parseInt(searchParams.get("limit") || "20")
  const skip = (page - 1) * limit
  
  // Query with skip/take
  const items = await prisma.model.findMany({
    skip, take: limit, ...
  })
  
  return NextResponse.json({
    data: items,
    hasMore: items.length === limit
  })

Relationship Includes:
  const item = await prisma.definition.findUnique({
    where: { id: definitionId },
    include: {
      phrase: { include: { language: true } },
      votes: true,
      examples: { include: { votes: true } }
    }
  })
